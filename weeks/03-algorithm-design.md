# Week 3 — Principles of Parallel Algorithm Design

> Syllabus (TR): *Paralel Algoritma Tasarımının İlkeleri*

**Previous:** [Week 2](02-platforms.md) · **Next:** [Week 4](04-communication-i.md)

## Goals
- Decompose a problem into tasks and map them onto processes.

## Key concepts
- **Decomposition** into tasks; task dependency graph; granularity (fine vs. coarse).
- **Degree of concurrency**: maximum, average; critical path length.
- Decomposition techniques: recursive, data, exploratory, speculative, hybrid.
- **Mapping** for load balance and minimal interaction: static vs. dynamic.
- Reducing interaction overhead: maximize locality, overlap computation with communication.
