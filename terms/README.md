# Terms

One folder per cohort. Everything belonging to a single run of the course — that
term's assignments, notes and submissions — lives in its own folder.

| Term | Whose | What is here |
|------|-------|-------------|
| [2023-2024-spring](2023-2024-spring/) | Mustafa Arınmış | Two homeworks and a midterm project, from when the course was coded CSE 440 |

The lab code in [`labs/`](../labs/) is shared and kept working; it is not filed by
term because it is the course's permanent starting material.

## Adding your term

```
terms/2026-2027-fall/
├── README.md      instructor, schedule, exam dates, whose work this is
├── assignments/   the five graded assignments
└── notes/
```

Write the README first. A folder of files with no attribution is much less useful
to the next person than three lines saying who made it and when.
